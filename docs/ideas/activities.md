# LOCKED — Activity Set (English app)

**Status:** Locked · **Date locked:** 2026-10-08
**Related:** [scene-simulation-concept.md](scene-simulation-concept.md) (the Scene activity)

> No activity is guaranteed fun — every one must be tested with 20–30 real learners and cut
> again if people skip, rush or complain.

## Final list (9 activities + the Scene)

| # | Activity | What it does | Time |
|---|---|---|---|
| 1 | **Picture Talk** | First meeting: phrase + audio + Uzbek/Russian meaning. After that: picture only → learner **says** the phrase | ~10s |
| 2 | **Build the Sentence** | Tap word tiles into order, then read the sentence aloud | ~15s |
| 3 | **Overheard** | Two town characters talk (no text) → one question → text appears; sometimes fill a missing word | ~30s |
| 4 | **Echo** | Repeat a character's line right after them (shadowing); voice compared to theirs | ~15s |
| 5 | **Sound Duel** | Fast game: "ship or sheep?" — tap what you hear, then say both (th, w/v, vowel length) | ~20s |
| 6 | **Spot the Rule** | 4 example sentences → guess the pattern → 2-line Uzbek/Russian confirmation | ≤30s |
| 7 | **Fix It** | A character's message has a typical Uzbek/Russian mistake ("She is my brother", "three book") → learner fixes it | ~15s |
| 8 | **Quick Reply** | One character line → learner replies aloud → character reacts (micro-scene) | ~20s |
| 9 | **Memory Review** | Mix of the above using words due for review (FSRS) **and the learner's own past mistakes** | 1–5 min |
| 🎬 | **Scene** | The big task at the end of each unit | 4–5 min |

**Quick Win** is a *mode*, not an activity: a 60-second Memory Review for tired days.

## Cut (and why)

| Cut | Reason |
|---|---|
| Phrase Cards | Passive swiping — merged into Picture Talk |
| Catch the Word | Feels like school dictation — merged into Overheard |
| Town Chat | High "AI slop" risk (fake, spammy AI texting) — cut for now |
| Mistake Notebook | A list to read is boring — merged into Memory Review |

## Anti-boredom rules

1. Never more than 2–3 of the same activity in a row.
2. Every activity under 30 seconds (except Scene and Review).
3. Everything is part of the town story — same characters everywhere, no random sentences.
4. Satisfying feedback: sounds, haptics, character reactions — not generic text.
5. **"Can't speak now"** (updated 2026-10-08, works like Duolingo's) — one tap turns speaking off
   for the session:
   - **Speaking-only exercises** (Echo, Say Both, Quick Reply) are skipped **as a whole** and saved for
     later. The same happens in Headphones/Silent mode.
   - **Recall exercises** (Picture Talk, Fix It "say" variant) switch to word tiles.
   - "Speaking is off · Turn on" brings speaking back; saved exercises return.
   - No double confirmations: the tap acts immediately.
6. Small surprises: character jokes, occasional twists.

## Anti-"AI slop" rules

- **Humans write or approve all core content** (stories, scripts, mistakes, explanations) —
  AI may draft, nothing ships unapproved (see [teaching-programme.md](teaching-programme.md)).
- **AI only where it adds real value:** reacting to what the learner actually said.
- Characters reply in 1–2 sentences, like real people.
- No generic praise after everything; no robotic voices; no inconsistent AI-generated art;
  no purposeless chit-chat.
